### 3.2 Vision Proxy (Generic)

**File**: `src/provider/vision/model.ts:53`

```typescript
// Change from:
const candidates = allModels.filter((m) => m.vendor !== "deepseek");

// To configurable exclusion:
const excludedVendors = this.config.excludedVendors ?? ["deepseek"];
const candidates = allModels.filter((m) => !excludedVendors.includes(m.vendor));
```

### 3.3 Transparent Vision Proxy Integration

The vision proxy from DeepSeek extension (`src/provider/vision/`) is already 95% generic. It will work with any provider that doesn't support vision natively.
