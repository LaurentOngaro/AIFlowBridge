# Screenshots

> Part of the [AIFlowBridge documentation](../README.md).

Every capture currently shipped with the extension.
The dashboard itself is the reference view: open it with `Ctrl+Alt+M` (`Cmd+Alt+M` on macOS) or run `AIFlowBridge: Show metrics dashboard`.

Captures from releases before 2.15.5 were removed from this page and from the packaged extension: they showed a dashboard that no longer exists, and shipping them cost 1.5 MB on every Marketplace download for nothing.
The Git history keeps them if you ever need to look at one.
